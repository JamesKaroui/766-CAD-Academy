# 766 CAD Academy

FRC mechanical design + Onshape course for Team 766, built to run as an Onshape right-panel extension.

`index.html` is the whole course (one self-contained file). Progress is saved in your browser.

## Onshape Action URL
```
https://jameskaroui.github.io/766-CAD-Academy/?documentId={$documentId}&workspaceId={$workspaceOrVersionId}&elementId={$elementId}
```
